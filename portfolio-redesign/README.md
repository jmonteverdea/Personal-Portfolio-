# portfolio-redesign

Working folder for the portfolio rebuild. Hand off to Claude Code only after the pre-flight audit returns GO.

## Structure
```
portfolio-redesign/
  content/            markdown copy for every section
  assets/
    images/           headshot, OG image, favicon source
    logos/            employer logos (SVG preferred)
    projects/         project photography (1600px+ wide)
    video/            drone or product clips (<10MB each)
    docs/             CV PDF, CEDES guide, certificates
  reference/          screenshot of current site, inspiration links
```

## Pre-flight checklist (re-run before handoff)
- [ ] All TODOs in content/ resolved
- [ ] Every case study has a quantified outcome
- [ ] Headshot meets spec
- [ ] OG image + favicon source in place
- [ ] All 4 employer logos present
- [ ] At least 4 project photos at 1600px+
- [ ] Video clips on-brand, under 10MB each
- [ ] CV PDF renamed clean
- [ ] reference/current-site.md + inspiration-links.md filled in
