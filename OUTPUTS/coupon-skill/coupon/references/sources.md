# Search queries

Replace `<store>` with the store name, `<item>` with the product or model number, and `<month year>` with the current month and year. Run the store and creator queries first. They have the highest hit rate.

## The store itself

- `<store> canada promo code`
- `<store> first order discount`
- `<store> newsletter discount` or `<store> sms discount`
- `site:<store domain> promo` and `site:<store domain> discount`
- `<store> student discount` (only if Jorge qualifies)

Also open the store home page and look for a banner, a signup popup, and footer links named Offers, Deals or Promotions.

## Creator and partner codes

- `"<store>" "use code"`
- `<store> discount code youtube`
- `<store> code podcast`
- `<store> affiliate code <item>`
- `<item> review <store> code`

## Community, last 30 days

- `site:forums.redflagdeals.com <store>`
- `<store> promo code reddit`
- `<store> code <month year>`

Check post dates. Ignore anything older than 30 days unless it is the store's own evergreen offer.

## Coupon sites (leads only)

- `<store> promo code retailmenot`
- `<store> coupon couponfollow`
- `<store> dealspotr`

Only take codes that show a recent "last worked" date or user confirmation.

## Stacking and alternatives

- `<store> rakuten canada cashback`
- `<store> great canadian rebates`
- `<store> gift card costco`
- `<store> price match policy canada`
- `<store> price adjustment policy`
- `<item> price canada`
- `<store> black friday <year>` or `<store> sale dates <year>`
- For Amazon.ca: `camelcamelcamel <item>`
