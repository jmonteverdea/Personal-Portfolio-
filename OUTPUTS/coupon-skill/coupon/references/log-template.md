# Coupon log template

Header for a new `OUTPUTS/coupon/coupon-log.md`:

```
# Coupon log

Newest entries at the bottom. One entry per hunt.
```

One entry per hunt:

```
## YYYY-MM-DD | <store> | <item>

- Baseline: $X CAD all-in
- Final: $Y CAD all-in (saved $Z)
- Platform: Shopify / WooCommerce / Amazon / other
- Codes:
  - CODE1 | Verified | -$12.00 | source: <link>
  - CODE2 | Failed | "This code is not valid" | source: <link>
  - CODE3 | Conditional | min spend $100 | source: <link>
- Stacked: Rakuten 5% (yes), Costco gift card 20% (yes)
- Notes: anything useful next time, such as "promo field needs login" or "locks after 5 tries"
```
